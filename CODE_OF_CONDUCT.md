# Code of Conduct

## Project Notice

This project is a private, proprietary codebase. It is not open to public contributions or open-source distribution. 

## Integrity and Compliance

All work submitted here adheres to strict integrity and confidentiality policies:
- **Original Work**: The core logic, architecture, and implementation are the exclusive property of the project authors unless explicitly cited.
- **Attribution**: Third-party libraries, frameworks, and tools (such as React, Flask, MediaPipe, FaceNet) are used in accordance with their respective licenses and are credited properly in the documentation.
- **Unauthorized Distribution**: Copying or distributing this code outside of authorized evaluation environments is strictly prohibited.

## Collaboration

For the project team members and authorized reviewers interacting with this repository:
- Maintain professionalism and constructive communication during code reviews and evaluations.
- Ensure all modifications and reviews are conducted within authorized channels.

## Contact

For questions regarding the project's source code, authorized personnel should contact the project maintainers directly.
